Addon · Flex

Deux axes. Trois mots-clés.

flex y empile verticalement. flex x aligne horizontalement. Ajoutez center, space, start — voilà l'API.

← Tous les addons Couleurs Dégradés Grilles Flex Typographie Tailles

Vertical · flex y

Empile les enfants haut-vers-bas. Ajoutez g-{n} pour le gap, center pour l'alignement.

flex y g-12
flex y center g-12
flex y space

Horizontal · flex x

Aligne les enfants gauche-vers-droite. Mêmes modificateurs, axe différent.

flex x g-12
flex x center y center
flex x space y center
