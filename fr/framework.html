Six modules autour du noyau fluide

Addons

Le fluide est le framework. Ces six addons sont optionnels. Utilisez ceux qu'il vous faut, ignorez le reste.

Couleurs

Système de couleurs OKLCH. Trois teintes, seize variantes par couleur, modificateurs d'opacité et de luminosité automatiques.

Explorer →

Dégradés

Syntaxe Emmet. Linéaire, radial, animé. from-brand to-accent d-r — voilà l'API.

Explorer →

Grilles

Trois paradigmes : auto-fit pour les cartes, 12 colonnes classiques pour les layouts, notation fractionnaire pour le contrôle précis.

Explorer →

Grille dorée

Quatre pistes inégales issues du nombre d’or. Un élément déclare un rôle — rail, main, spill — jamais une largeur.

Explorer →

Flex

Deux axes, trois mots-clés. flex y, flex x, center, space. C'est tout.

Explorer →

Typographie

Typographie fluide avec trois modificateurs d'intensité. Du texte qui coule du mobile au desktop sans media query.

Explorer →

Tailles

Un nombre, quatre saveurs. Padding, marge, gap, largeur, hauteur — tous sur la même échelle fluide.

Explorer →

Outils

Deux outils interactifs pour générer des thèmes et explorer les variables.

Auto Theme

Déposez une image, obtenez un thème OKLCH. Brand, accent, extra extraits automatiquement.

Ouvrir dans le Playground →

JS Calculator

Configurez votre échelle, voyez chaque variable et classe générée. Aperçu live, sans installation.

Ouvrir dans le Playground →
